# Source and research provenance

This repository is the complete `cooperative-computing-lab/cctools` repository, cloned from `master` at `653f40853919bf6626fddaa543e086e4129dcc3b` on 2026-10-21 with its full Git history. Upstream source, tools, documentation, `COPYING`, `CREDITS`, per-file notices, and the original README (`README.upstream.md`) are retained. The inherited release workflow is preserved byte-for-byte in `.github/upstream-workflows/testing.yml` and is inactive; `.github/workflows/verify.yml` is the local project's read-only native verification workflow.

The application foundation is Cooperative Computing Tools, particularly its existing Linux `parrot_run` syscall interposition runtime and Chirp protocol/server. Parrot and Chirp remain upstream implementations; this project does not reimplement their system-call tracing or storage protocol. See the [Parrot manual](https://cctools.readthedocs.io/en/latest/parrot/), [Chirp manual](https://cctools.readthedocs.io/en/latest/chirp/), and the [upstream repository](https://github.com/cooperative-computing-lab/cctools).

The coursework target is Carrot, presented in the [Stanford CS244b 2024 program](https://www.scs.stanford.edu/24sp-cs244b/labs/program.html) and its [project paper](https://www.scs.stanford.edu/24sp-cs244b/projects/Carrot_A_Distributed_Interpsition_Library_for_Networking_and_File_System.pdf). The paper says Carrot was inspired by Parrot. The exact Carrot student repository has no license, so no code from it is copied here.

The small failure-exploration extension follows the observed-path alternation described in Alvaro et al., [“Automating Failure Testing Research at Internet Scale,” SoCC 2016](https://people.ucsc.edu/~palvaro/socc16.pdf): derive minimal fault sets that hit observed successful lineages, inject a derived hypothesis, and merge any newly observed successful alternative path before deriving the next cut. This implementation enumerates minimal hitting sets for at most 16 named endpoints. It does not implement all of LDFI, a SAT solver, distributed tracing infrastructure, or a fault-tolerance certification.

The inherited CCTools application and this combined repository are covered by the preserved GNU GPL version 2 license and existing notices. New source files include their own license notices. The only inherited source change adds an opt-in `chirp_server --no-advertise` flag; its file carries a modification notice and existing default registration behavior is unchanged.
